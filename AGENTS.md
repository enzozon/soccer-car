# Soccer Car
- Português brasileiro; Conventional Commits sem atribuição de IA.
- Jogo autoral: não importar código, modelos, marcas ou áudio de Rocket League ou Car Soccer.
- TypeScript estrito, Three.js e APIs nativas. Sem backend obrigatório.
- Simulação independente de renderização e entrada. Y para cima; gol adversário em Z negativo; heading 0 aponta para Z negativo.
- Verificar com npm run check e testes de navegador para fluxos interativos.
- Manter fallback Canvas 2D, pausa ao perder foco e limite de passos de física por frame.
